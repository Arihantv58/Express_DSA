# Express_DSA

Welcome to my **Express_DSA** repository! This repo contains a structured collection of Java programs and solutions to various data structure problems, primarily solved on platforms like LeetCode. Each program is categorized by data structure type, making it easy to navigate and learn from.

## Repository Structure
The repository is organized into folders, with each folder dedicated to a specific data structure. Below is the structure:

```
Java-DS-Practice/
|
├── Arrays/
│   ├── FindMaximum.java
│   ├── TwoSum.java
│   └── RotateArray.java
│
├── LinkedLists/
│   ├── ReverseLinkedList.java
│   ├── DetectCycle.java
│   └── MergeTwoLists.java
│
├── Stacks/
│   ├── ValidParentheses.java
│   ├── MinStack.java
│   └── EvaluateExpression.java
│
├── Queues/
│   ├── CircularQueue.java

│   └── SlidingWindowMaximum.java
│

│   ├── BinaryTreeInorderTraversal.java
│   ├── MaximumDepthOfBinaryTree.java

│   ├── BFS.java
│   ├── DFS.java
│   └── DijkstraAlgorithm.java
│
└── README.md
```

## Usage
1. **Clone the Repository:**
   ```bash
   git clone https://github.com/Arihantv58/Express_DSA.git
   cd Express_DSA
   ```

2. **Navigate to a Folder:**
   Open any folder corresponding to a data structure, and you will find Java programs addressing different problems.

3. **Run a Program:**
   Compile and run any program using the following commands:
   ```bash
   javac ProgramName.java
   java ProgramName
   ```
